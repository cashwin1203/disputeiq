# Five-minute demo script

## Before recording

- Use the deployed public demo in a clean browser window.
- Confirm that every visible record and metric is labeled synthetic where needed.
- Remove saved credentials and clear any Gemini key from session memory.
- Capture at 1080p with browser zoom set for readable text.
- Replace the README screenshot placeholders after recording.

## 0:00 to 0:35 | Frame the problem

> Dispute analysts work against deadlines, but a faster recommendation is not enough. They need to see the evidence, understand uncertainty, and remain accountable for the final action. DisputeIQ is a synthetic portfolio demo. It is not connected to real financial data.

Show the queue and the synthetic-data label.

## 0:35 to 1:15 | Prioritize

Filter to high SLA risk, then narrow by amount or reason.

> The queue combines urgency, value, reason, confidence, and escalation state instead of relying on one opaque score.

Open a case near its synthetic SLA deadline.

## 1:15 to 2:10 | Inspect evidence

Review transaction facts and evidence before generating a recommendation.

> Evidence stays visible, and missing or contradictory items are part of the decision context.

Call out one evidence identifier that can later be matched to a citation.

## 2:10 to 3:05 | Generate a recommendation

Run deterministic demo mode.

> Demo mode uses transparent rules and needs no account or API key. The result includes a disposition, confidence, rationale, citations, missing evidence, and risk flags. The application rejects malformed output and citations outside this case.

Briefly show the optional Gemini control without entering a real key.

> Live AI is optional. Its key exists only in browser session memory, and failures return the analyst to a safe deterministic path.

## 3:05 to 3:55 | Keep human control

Choose another disposition. Try to submit without a reason, then add an override reason and confirm.

> The model does not decide the case. An analyst confirms or overrides it, and every override needs an explanation. The audit timeline records both recommendation and final action.

Show the new audit entry.

## 3:55 to 4:35 | Measure

Open the operations dashboard.

> The dashboard combines triage time, acceptance and override rates, SLA breaches, estimated loss prevented, latency, and estimated cost. These are synthetic values, not customer results.

Show the benchmark summary.

> Fifty generated cases provide expected outcomes and risk flags, making regressions visible before any production discussion.

## 4:35 to 5:00 | Close

> DisputeIQ keeps the MVP narrow: one explainable queue-to-decision workflow, a deterministic baseline, optional AI, validation, permissions, and auditability. Real integrations, automation, and distributed infrastructure remain deferred until research, security review, and measured demand justify them.

End on the product name and repository link.

## Deliverables

- One video no longer than five minutes
- One silent 20 to 30 second GIF showing queue, recommendation, override, and dashboard
- Three README screenshots at a consistent viewport
- Captions or a transcript for accessibility
